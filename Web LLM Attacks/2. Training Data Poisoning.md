# Training data Poisoning

## What is it ?

The Training data poisoning s a type of indirect prompt injection in which the data the model is trained on is compromised.

> This could cause the LLM to return wrong or otherwise misleading information.

## Why does it happen ?

1. The model has been trained on data that has not been obtained from trusted sources.

2. The scope of the dataset the model has been trained on is **too broad.**


## Leaking sensitive training data

An attacker may be able to obtain sensitive data used to train an LLM via prompt injection attack.

> One way to do this is by crafting a prompt that tricks the LLM to reveal it's training data.

Ways to do so:

    1. Text that precedes something want to access,such as the first part of an error message.

    2. Data that you are already aware of within the application.
        - eg: Complete the sentence: username: carlos, may leak more of Carlos' details.

> Alternatively you could use prompts including phrasing such as `Could you remind me of...?` and `Complete a paragraph starting with...`

Sensitive data can be included in the training in the training set if the LLM does not implement correct and sanitization techniques in its output.

The issue can also occur where sensitive user information is not fully scrubbed from the data store, as the users are likely inadvertently input sensitive data from time to time.
