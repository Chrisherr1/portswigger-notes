# Web Cache Deception — delimiter testing wordlist
# Source: PortSwigger (https://portswigger.net/web-security/web-cache-deception/wcd-lab-delimiter-list)
# Plus non-printable control characters from lesson 7 (Delimiter Decoding Discrepancies)
#
# Usage notes:
# - Turn OFF automatic URL/character encoding in your tool (e.g. Burp Repeater/Intruder)

#   before testing this list — you need the raw and encoded forms sent exactly as written.

# - Test against the target endpoint as: /path<char>aaa  and  /path<char>aaa.<ext>

#   trying a range of extensions (.css, .ico, .js, .exe, etc.) per lesson 4.
